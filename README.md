# 🏀 HOOPMATE

Aplikasi web untuk mengelola pertandingan basket 3v3 dengan mudah. Mulai dari mengatur pemain, membagi tim secara acak, mengelola jadwal pertandingan, hingga mencatat skor dan klasemen.

## ✨ Fitur

- **Manajemen Pemain** — Menambahkan, mengubah, dan menghapus pemain.
- **Pembagian Tim Acak** — Membagi pemain menjadi tim beranggotakan 3 orang.
- **Jadwal Pertandingan** — Mengatur pertandingan agar setiap tim saling bertemu.
- **Papan Skor** — Mencatat skor pertandingan.
- **Stopwatch** — Mengatur waktu pertandingan.
- **Klasemen** — Melihat peringkat tim berdasarkan hasil pertandingan.
- **Riwayat Pertandingan** — Melihat hasil pertandingan sebelumnya.
